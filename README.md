# SoloLuck Miner has moved

This repository is an early snapshot and is no longer maintained. It is kept only
so old links resolve.

**The maintained code, and every signed release, is at
https://github.com/sololuckio/sololuck** (miner under `miner/`).

Download the current Windows build from
https://github.com/sololuckio/sololuck/releases/latest — releases are GPG-signed,
and the app can verify its own build against the published checksum.

Do not build from the copy in this repository. It predates the CPU hard-cap, the
Defender exclusion that keeps the fast mining engine from being quarantined, and
the Bitcoin address validator.

The pool is **0% fee** — an old script in this repository said otherwise, which
was never true of the pool.

https://sololuck.io
